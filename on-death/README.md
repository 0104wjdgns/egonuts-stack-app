# 에고너츠 — 죽음에 관하여

「고독과 상실」 앱(루트 `/`)을 통째로 복사해 만든 **독립 회차**. 주소는 `/on-death/`.
코드·배색·저장 키가 모두 이 폴더 안에만 있어서, 여기를 고쳐도 고독과 상실은 그대로다
(루트 `index.html`, `/assets`, `/rounds/solitude`는 건드리지 않는다).

참고 도서: 미하엘 하우스켈러 『왜 살아야 하는가』 (김재경 옮김, 추수밭)

## 폴더 구조
```
on-death/
  index.html            이 회차 앱 (경로는 모두 /on-death/…)
  assets/               루트 assets 복사본 — 이 회차 전용
  round.json            질문 · 배색 · 참고 출처
  materials/qN.txt      질문 N 뒤 참고 자료 (Q1~Q5)
  materials/qN.jpg      자료 상단 이미지 자리 (Q1~Q5) — 아직 없음
  materials/book.jpg    Q6 뒤 출처 페이지의 책 표지 자리 — 아직 없음
```
이미지는 파일이 없으면 자리째 숨겨지고, 같은 이름으로 넣으면 바로 나타난다.

## 배색
- main `#2c1f3d` 어스름 보라 (배경)
- point `#d4b27a` 촛불빛 (포인트)

## 자료 텍스트 규칙
루트 앱 규칙(첫 줄 = 제목, `"`로 시작 = 인용, `—`로 시작 = 출처, `**굵게**`)에 하나를 더했다.
- `§`로 시작 = **파트**(책의 몇 장). 제목 앞에 두면 제목 위 머리표, 본문 중간에 두면 소단락 머리표.

## 저장
- 답: `localStorage["egonuts-stack-on-death"]`
- 관리자 스위치: `/on-death/?admin=1` (켜기) · `?admin=0` (끄기) — 다른 회차와 따로 켜고 끈다
