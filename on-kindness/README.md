# 에고너츠 — 친절과 용기

「고통과 의미」(`/on-suffering/`)를 템플릿으로 복사해 만든 **독립 회차**. 주소는 `/on-kindness/`.
코드·배색·저장 키가 모두 이 폴더 안에만 있어서, 여기를 고쳐도 다른 회차는 그대로다.

출발은 정훈의 훈련병 시절 일기 「소나기」(2020년 봄). 참고도서는 『상처받을 용기』(안전기지). 읽기자료는 일기의 장면을 짧게 옮긴 안내이며, 책 문장을 인용하지 않는다.

## 폴더 구조
```
on-kindness/
  index.html            이 회차 앱 (경로는 모두 /on-kindness/…)
  assets/               on-death assets 복사본 — 이 회차 전용 (흰 바탕에 맞게 조정)
  round.json            질문 · 배색 · 참고 출처
  materials/qN.txt      질문 N 뒤 참고 자료 (Q1~Q5)
  materials/qN.jpg      자료 상단 이미지 자리 (Q1~Q5)
  materials/book.jpg    Q6 뒤 출처 페이지의 책 표지
```
이미지는 파일이 없으면 자리째 숨겨지고, 같은 이름으로 넣으면 바로 나타난다.

## 이미지
자료 그림은 이 회차를 위해 만든 노을·비 갠 하늘 그림이다. 외부 사진이나 책 표지를 쓰지 않는다.

## 배색 — 노을 코랄 · 비 갠 하늘
- 진행 바탕: 깊은 남색 → 노을 코랄 `#D9734E` → 크림. 하늘색 `#7FA7C9`는 표지와 그림에 쓴다.
- 카드: main `#fff8f4` 밝은 종이, point `#D9734E`, strong `#8d3e28`
- 질문 화면의 글자 대비는 각 진행도에서 4.5:1 이상이 되도록 스톱을 잡아 두었다.

## 화면 경험 (리더스클럽 「용서」 방식을 옮김, 2026.11)
- 흐름: 시네마틱 표지 → 목차 → (질문 → 참고 자료)×6 → 카드에 넣을 이름 → 카드 덱
- 표지: 마스트 → 제목(마지막 낱말 노을빛) → 밑줄 → `intro.coreQuestionLines`가 한 줄씩. 스크롤·탭·키로 시작
- 질문: `01_ 소주제` 번호가 가운데서 크게 떴다 제자리로(FLIP), 질문은 단어 단위로. 입력칸은 움직이지 않는다
- 자료: 기존 이미지·텍스트·책 소개를 한 장의 종이로 감싸 처음 볼 때만 펼친다. 아래에 `materialNote` 대기 안내
- 바탕: 진행할수록 깊은 남색 → 노을 → 크림 (`app.js` `SKY`). 어두운 구간 `body.dark`, 중간 밝기 `body.mid`
- 완료: 카드 덱 · 저장/공유 → 맨 아래 마무리 인사. 크림 → 노을 그라데이션
- 한 번 본 화면 · `prefers-reduced-motion`은 애니메이션 없이 바로
- 카드 덱 색은 `round.json` `colors`(밝은 종이 · 노을 코랄)로 그린다 — 진행 바탕과 분리
- 휴대폰: 뒤로가기 = 이전 단계(방문 기록), 새로고침하면 보던 단계에서 이어서. 뒤로/다음은 화면 아래 고정(입력 중엔 제자리), 버튼 48px, 입력칸 아래 "자동 저장됨 · 시:분 · N자", 표지 안내는 터치 기기면 "밀어 올리거나 눌러서 시작"

## 자료 텍스트 규칙
첫 줄 = 제목, `"`로 시작 = 인용, `—`로 시작 = 그 문단 아래 작은 출처, `§`로 시작 = 파트. 첫 문단 바로 다음이 출처면 제목 없이 발췌로 읽는다.
읽기자료는 일기 「소나기」의 장면을 짧게 옮긴 안내이고, 문단 아래 출처는 `정훈의 일기 「소나기」에서`이다. 책의 문장은 인용하지 않는다.
